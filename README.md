### What is Torren Agent?

Torren Agent is a specialized skill built for autonomous AI agents operating on **Base**.  
It helps agents manage treasury, optimize yield, handle gas efficiently, and interact with the Torren protocol.

### Features

- Agent Treasury Management
- Yield Strategy Recommendations on Base
- Gas Optimization for Agents
- Torren Protocol Guidance
- Clean & actionable responses
